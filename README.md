# 🛠️ Engenharia de Software: Algoritmos e Soluções Computacionais com Java

Este repositório centraliza uma árvore evolutiva de soluções de software focada no desenvolvimento de lógica aplicada, arquitetura limpa, tratamento robusto de erros e a implementação prática do paradigma de Programação Orientada a Objetos (POO).

## 🚀 Competências e Ecossistema Técnico
- **Linguagem:** Java (JDK 17+)
- **Gerenciador de Projetos:** Maven (Estruturação profissional via `pom.xml`)
- **Paradigma:** Estruturado e Orientado a Objetos (POO)
- **Tratamento de Exceções:** Fluxos seguros de dados com cláusulas `try-catch-finally`.
- **Interfaces e UX/UI:** Coleta e exibição de dados via Console e caixas de diálogo gráficas (`javax.swing.JOptionPane`).

---

## 📂 Arquitetura dos Módulos de Engenharia

### 🔹 [TP01 & TP02](./) - Lógica Comercial e Estruturas de Decisão
Desenvolvimento focado na resolução algorítmica de regras de negócios dinâmicas e validação de intervalos.
- **Automação Financeira:** Algoritmos de margem de lucro variável (`CalculadoraDeVenda`), desconto progressivo em PDV (`DescontoProduto`) e precificação escalonada de convênios (`PlanodeSalud`).
- **Análise Numérica e Conversões:** Árvore de decisão otimizada para ordenação manual de variáveis de tamanho fixo (`OrdemCrescente`), engenharia de conversão térmica (`ConversaoTemperatura`) e loops iterativos (`NumerosParesIntervalo`).

### 🔹 [TP03 & TP04](./) - Modularização, Resolução Matemática e Resiliência
Implementação focada em desacoplamento de código por meio de sub-rotinas (métodos) e blindagem contra falhas críticas de entrada de dados.
- **Encapsulamento de Métodos:** Funções isoladas para cálculo de progressões aritméticas complexas, conversão trigonométrica (`GrausRadianos`) e funções fatoriais de alta escala (`Fatorioso`).
- **Tratamento de Erros Profissional:** Implementação de regras de contorno de exceções reais com disparo de mensagens via `IllegalArgumentException` em casos de intervalos numéricos e médias acadêmicas fora do escopo de negócio.
- **Algoritmos Avançados:** Lógica aplicada para geração de segmento Fibonacci dinâmico e crivo de verificação analítica de números primos.

### 🔹 [TP05](./) - Programação Orientada a Objetos (POO) e Modelagem de Domínio
Consolidação das diretrizes de engenharia de software voltadas à reutilização de código e modelagem de entidades reais de mercado.
- **Calculadora Orientada a Objetos:** Migração de lógica procedural para uma estrutura de classes e métodos encapsulados focados em operações aritméticas limpas.
- **Modelagem de Domínios Relacionais (Herança e Polimorfismo):** Estruturação de herança multinível (`Animal` ➔ `Cachorro` ➔ `Cocker`) utilizando visibilidade privada, métodos acessores (Getters/Setters) e sobrescritas de métodos nativos (`@Override`).
- **Interface Gráfica Embutida:** Integração do fluxo operacional do software através de componentes visuais baseados na biblioteca nativa Swing.
